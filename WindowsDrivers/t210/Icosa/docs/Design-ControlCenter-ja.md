# Switch コントロールセンター：設計

作成: 2026-10-26（Claude）

## 目的

Switch 専用の管理ソフトを作る。L4T の上のバーや、ノート PC のメーカー製管理アプリのようなもの。今の常駐アプリ `SwitchClock.exe`（CPU のプロファイルと明るさ）を土台にして、置き換える。

- **名前（案）:** 「Switch コントロールセンター」。実行ファイルは `SwitchCenter.exe`。
- **通知領域:** 今と同じアイコンを残す。クリックすると、今のメニュー（プロファイル、明るさ）が出る。メニューの「コントロールセンターを開く」で、大きな画面を開く。

## 技術の選択

| 項目 | 選択 | 理由 |
|---|---|---|
| ランタイム | **.NET 8（LTS）、win-arm64、自己完結型** | Switch のネイティブ（ARM64）で動くので、x86 エミュレーションの今より軽い。必要なものをすべて同梱するので、Switch 側に何も入れなくてよい |
| 画面 | WinForms | .NET 8 の ARM64 で動く。今の常駐アプリのコードをそのまま移せる |
| 配り方 | 1つのフォルダー（exe と同梱の DLL）。ZIP にして GitHub の Releases にも置ける | |
| ビルド | PC の .NET SDK（今は 10.0.301）で、`net8.0-windows` 向けに publish する | |

**[未確認]** .NET 8 の ARM64 版が、この Windows 10（19044）で動くか。最初に、小さな試験用の exe で確かめる（段階0）。動かなければ、今の .NET Framework 4（x86）のまま作る。

## データの取り方

| 情報 | 取り方 | 状態 |
|---|---|---|
| CPU のクロック、電圧、プロファイル、温度、温度による制限 | `\\.\SwitchCpu` の IOCTL（取得・設定） | ある |
| 画面の明るさ、画面の状態 | `\\.\SwitchBacklight` の IOCTL（取得・設定） | ある |
| SoC と基板の温度、ファンの duty | `Services\switchfan\Parameters`（TempSoC、TempBoard、Duty） | ある |
| バッテリー残量、AC、充電中 | Windows 標準の電源の API（バッテリーのドライバー経由） | ある |
| バッテリーの電圧 | `Services\switchbattery\Parameters`（LastVoltage） | ある |
| 各ドライバーの状態（正常／エラーの番号）と版 | Windows の PnP の情報（SetupAPI／WMI）と、各ドライバーの `DriverVersion` | ある |
| ファンの回転数 | 今は UEFI だけで測っている | **ドライバーに足す必要がある** |
| 充電の電圧と電流（PD の契約、BQ24193 の状態） | 今は UEFI だけ | **ドライバーに足す必要がある** |

- 記録（レジストリ）は、普通のユーザーでも読める。
- 設定を変える IOCTL は、ドライバーがログイン中のユーザーに許している（CPU、明るさ）。

## 画面（最初の版）

### 1. 概要
- 大きな数字で、次を並べる。
  - CPU のクロック
  - SoC の温度
  - バッテリー残量
  - 画面の明るさ
- その下に、次の情報を出す。
  - 電圧
  - 基板の温度
  - ファンの duty
  - AC と充電の状態
  - 温度による制限中かどうか
- 直近の数分の温度と CPU クロックの小さなグラフを出す。
- 2秒ごとに更新する。画面を閉じている間は、通知領域のアイコンだけを更新する。

### 2. パフォーマンス
- **CPU のプロファイル:** 一覧から選ぶ（今のメニューと同じ）。各プロファイルのクロックと電圧も表示する。
- **試験的なプロファイル:** 確認の画面を出す。
- **ログインしたときの扱い:** 前回のプロファイルに戻す（試験的なものは除く）。今と同じ動き。
- **[あとで]** 温度による制限のしきい値（今は 80/70 ℃ 固定）、ファンの段階の調整。どちらも、ドライバーが設定を読むように直す必要がある。

### 3. 画面
- **明るさ:** スライダー（8〜255 を 0〜100% で表示）。動かすとすぐに変わる。
- **画面を暗くしたとき・消したときの動き:** 表示だけ（今は 1/3、0 で固定）。
- **[あとで]** タッチの向きの調整（今は `Touch.ps1 -Mode Calibrate`）。管理者の権限が要るので、段階3で扱う。

## あとの段階で足すタブ

- **電源:** 電源ボタンを押したときの動き（`powercfg`）、電池が少ないときの動き。
- **ドライバー:** 各ドライバーの状態と版、更新とインストール。管理者として実行する補助を通す。
- **記録:** 各ドライバーの記録を見る。困ったときの情報を1つの ZIP にまとめる。

## 段階

| 段階 | 内容 | 確かめること |
|---|---|---|
| 0 | .NET 8 の ARM64 版の試験用 exe を Switch で動かす | 起動するか。起動の速さ |
| 1 | 土台（ドライバーとのやり取りのクラス）と通知領域のアイコン。`SwitchClock` と同じことができる | 今の常駐アプリと置き換えられるか |
| 2 | コントロールセンターの画面（概要・パフォーマンス・画面）| 表示と操作 |
| 3 | 電源・ドライバー・記録のタブ。管理者として実行する補助 | |
| 並行 | ドライバー側の追加（ファンの回転数、充電の詳細、しきい値の設定） | |

## ソースの置き場所

- 作業用: `outputs\Windows-Drivers\SwitchCenter\`（`src\`、`build\`）
- 配る形: `outputs\Windows-Drivers\Switch-Center\`
- GitHub: `windows/SwitchCenter/`。動作を確かめてから入れる。
