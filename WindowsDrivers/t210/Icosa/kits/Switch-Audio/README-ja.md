# 音声（スピーカー）ドライバ `switchaudio`（試験中）

本体のスピーカーから Windows の音を出すドライバ。段階 1 では、スピーカーへの再生だけに対応する。

## 必要なもの

- **UEFI R402 以降**
  - R402 は、ACPI に音声のデバイス AUD0（`ACPI\SWOA0C01`）を加えている。
  - さらに、起動時に音声のクロックを入れ、コーデック（ALC5639）と I2S1 を準備したままにしておく。
- R402 より前の UEFI では、ドライバは音声のレジスタに触らずに止まる（コード 10）。クロックが止まった状態でレジスタを読むと、CPU が止まってしまうため。

## 入れ方

管理者の PowerShell で:

```
powershell -ExecutionPolicy Bypass -File .\Audio.ps1 -Mode Install
```

設定 > システム > サウンド に「スピーカー」が出れば、ドライバは動いている。

- 状態を見る: `-Mode Status`（ログは `C:\SwitchWOA-Audio.txt`）
- 外す: `-Mode Remove`

## しくみ（段階 1）

- PortCls の WaveRT ドライバ。対応する形式は 48 kHz、16 ビット、ステレオだけ。
- Windows が書き込む再生用のバッファを、ADMA のチャンネル 0 が ADMAIF1 に送る。そこから XBAR、I2S1、コーデック、スピーカーの順に流れる。
- 音量はコーデックで -18 dB に固定している。Windows の音量は、Windows がソフトウェアで調整する。

## まだできていないこと

- ヘッドホン（差したときの切り替え）
- マイク
- 音量をコーデック側で調整すること
- スリープ
