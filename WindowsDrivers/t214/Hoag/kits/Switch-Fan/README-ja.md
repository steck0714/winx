# ファンの自動制御：Nintendo Switch のファン制御ドライバー

## 中身

| ファイル | 内容 |
|---|---|
| `switchfan.sys` | KMDF ドライバー（ARM64、テスト署名）。ソースは `..\SwitchFan\src\switchfan.c` |
| `switchfan.inf` | `ACPI\SWOA0401` |
| `Fan.ps1` | Install、Status、Watch（温度と duty を2秒ごとに表示）、Remove |

## ドライバーの作り

- **使うリソース（DSDT の `FAN0`）:**
  - PWM コントローラー（0x7000A000）。書くのは **PWM_CSR_1（ファン）だけ**。
  - I2C1 上の TMP451（0x4C）。
- **前提:** ファンの 5V 電源、PWM のクロック、ピンの設定（LCD_GPIO2 → PWM1）は、UEFI R366 以降がすでにやっている。ドライバーは duty を変えるだけ。
- **制御:** 2秒ごとに、SoC（0x01）とボードの温度（0x00）を読み、高いほうで duty を決める。Hekate の段階に、オーバークロック用の上の段を2つ足した。

| 温度 | duty | 割合 |
|---|---|---|
| 68 ℃ 以上 | 236 | 100% |
| 60 ℃ 以上 | 153 | 65% |
| 52 ℃ 以上 | 102 | 43% |
| 47 ℃ 以上 | 76 | 32% |
| 42 ℃ 以上 | 51 | 22% |
| 40〜41 ℃ | 前の値のまま（最大 51） | |
| 39 ℃ 以下 | 0 | 停止 |

- **安全策:**
  - 温度センサーを3回続けて読めなかったら、65% にする。
  - センサーの接続を開けなかったときも、65% にする。
  - ドライバーが外れるときは、UEFI の既定値（32%）に戻す。
- **タイマー:** 単発の PASSIVE タイマーを、毎回かけ直す方式（バッテリーと同じ）。
- **記録:** `Services\switchfan\Parameters` に、TempSoC、TempBoard、Duty、Runs などを書く。

## 手順

1. **Switch を UEFI R372 で起動する。** ペイロードは `D:\Codex\coreboot-R372.rom`。段階3の I2C ドライバー（v3）が入っていること。
2. **このフォルダーを Switch に移す。** 例: `C:\SwitchWOA\Fan`。
3. **インストールする。**
   ```bat
   powershell -ExecutionPolicy Bypass -File C:\SwitchWOA\Fan\Fan.ps1 -Mode Install
   ```
4. **動きを見る。** 次を実行すると、温度と duty が2秒ごとに出る。Ctrl+C で止まる。
   ```bat
   powershell -ExecutionPolicy Bypass -File C:\SwitchWOA\Fan\Fan.ps1 -Mode Watch
   ```
   - 涼しいとき（39 ℃ 以下）は、ファンが止まる。
   - 負荷をかけて温度が上がると、ファンが強くなる。負荷は、たとえばブラウザーで重いページを開くなど。
5. **結果を共有する。** `-Mode Status` の出力を見せてほしい。

## 結果（2026-10-25、ユーザー報告）

- **R372 で正常に起動した。**
- **ファンは止まっている。** 今の使い方では、SoC がほとんど 40 ℃ を超えないため。GPU のドライバーが無く、CPU も 1020 MHz なので、発熱が少ない。
- **未確認:** 温度が上がったときに段階どおりに強くなるか。これは、CPU のクロックを上げたときや、重い処理をしたときに確かめる。

## v2（1.0.0.2）: 画面の明るさ

- **仕組み:** ファンと同じ PWM の部品で、バックライトの duty（`PWM_CSR_0`、0〜255）も変える。UEFI R376 以降が必要（R375 以前では、明るさは変わらない）。
- **明るさの保存:** 最後に選んだ明るさを `Parameters\Brightness` に保存し、次に起動したときに戻す。
- **画面のオフとの連動:** Windows が画面を消したら、バックライトも消す（duty 0）。画面が暗くなったら、明るさを 1/3 にする。電源ボタンで「画面を消す」にしたときにも、バックライトが消える。
- **アプリとの接続:** 常駐アプリ（SwitchClock）から `\\.\SwitchBacklight` で明るさを変える。ログインしているユーザーにも、変更を許している。
- **入れ方:** v1 と同じく `Fan.ps1 -Mode Install`。上書きされないときは、再起動する。

## もし起動しなくなったら

R371 の ROM で起動すれば、FAN0 が無い状態に戻る。ファンは、UEFI の 32% 固定で回る。
