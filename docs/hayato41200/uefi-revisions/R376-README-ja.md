# R376 — バックライトを PWM で動かす（R375 ベース）

## 変更点

- **今までの状態:** coreboot は、バックライトの PWM 入力（ピン LCD_BL_PWM = GPIO PV0）を、GPIO の High にしているだけだった。つまり、明るさは常に最大で、調整できなかった。
- **R376 の変更:** `R376BacklightPwm()` で、Hekate の `display_backlight_pwm_init()` と同じ設定にする。ファンの設定（R366）の直後に行う。
  1. PWM のクロックが動いているかを確かめる（R366 がすでに入れている）。動いていなければ何もしない。
  2. `PWM_CSR_0 = EN | (255 << 16)`。duty は 255/255 で、今までと同じ明るさ。
  3. ピン LCD_BL_PWM の機能を PWM0 にする。
  4. PV0 を GPIO から外す（CNF=0）。ここで、バックライトが PWM0 で動くようになる。
- **表示:** 前後の値を `R376 backlight before/after:` に表示する。
- **変えていないもの:** DSDT は R375 と同じ。Windows 側は、ファンのドライバー v2（同じ PWM の部品を使っている）が明るさを変える。

## 成果物と検証

- ROM: `D:\Codex\coreboot-R376.rom`
- SHA-256: `9afe426e0a8ba582aa13f60e9790e4447e4a790d2d46b6bd13c94432dacf444a`
- `EDK_SOURCE_RESTORE_MATCH=YES`。
- **実機の結果（2026-10-26、ユーザー報告）:** 動作確認 OK。ファンのドライバー v2 と常駐アプリも、次のことがすべて動いた。
  - 「画面の明るさ」で、明るさが変わる。
  - 電源ボタンで画面を消すと、バックライトも消える。
  - 再起動すると、選んだ明るさに戻る。

## 確かめること

1. **R376 で起動する。** 画面が今までどおり明るく表示されるか。
2. **起動中の表示を撮る。** 次の2行を見たい。
   - `R376 backlight before: CSR0=... LCD_BL_PWM=... PV0 cnf/oe/out=1/1/1`
   - `R376 backlight after: CSR0=807F0000 ... PV0 cnf=0`

## もし画面が暗くなったら

R375 の ROM で起動すれば、元に戻る。暗くなった場合でも、UEFI の画面は撮れないことがある。そのときは、画面が暗くなったということだけ教えてほしい。
