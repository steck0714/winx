# R366 実機結果（2026-10-24、ユーザー報告）

**[事実]** R366 で起動すると、**ファンが回った**。

UEFI の画面（`R366 fan before`、`fan set`、`rpm`、温度）は撮影していない。

## 追加の結果（`USB STATUS #3/#4` の写真）

- **ファン:** `duty=76/236 (32%) CSR1=80A00000`、**rpm=5070 / 5040**。回転数の読み取りもできている。
- **温度:** SoC=40℃、ボード=38〜39℃（CPU 1020 MHz、UEFI の画面を表示している状態）。
- **バッテリー:** 100%、4198mV、+1330mA。`FAULT=00`。
- **USB:** ハブ、RTL8153、レシーバー（046D:C547）、USB メモリ（056E:605F）、ハブの SD スロットがすべて列挙された（UsbIo=6）。UEFI でも FS のレシーバーが見えるようになっている。

## 未確認

- 回転数の読み取り（`rpm`）の値
- PWM のクロックを有効にする処理が走ったか（`R366 PWM clock enabled` の行が出たか）
- PCC4 と VBUS_EN0 の状態
- Windows で長時間使ったときの温度。Windows には温度を読む手段がまだ無い。UEFI の状態表示の `temp: SoC=` で、起動時の値だけは見られる。
