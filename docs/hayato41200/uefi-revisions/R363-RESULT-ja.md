# R363 実機結果（UEFI、2026-10-24）

構成: R363 + ELECOM DST-C30SV（USB-C ハブ）+ Anker Nano Charging Station。写真は `R362 USB STATUS #1` の後半と `#2`。

## 結果（写真から読んだ値）

**[事実]** **充電しながら、ハブ経由で USB ホストとして動いた。**

- **USB**（`P5=00000E03`: 接続あり、有効、High-Speed）
  - `UsbIo[0] 2109:2817 class=09`: VIA Labs のハブ（DST-C30SV の中身、USB 2.0 側）
  - `UsbIo[1] 0BDA:8153`: Realtek RTL8153（ハブの有線 LAN）
  - removable BlockIo が3つ（媒体全体が 0x3A38000 ブロック、約 29.8GB。パーティションが2つ）、SimpleFileSystem=1
- **充電**
  - `BQ: fast-charge`
  - `REG00=34`: HIZ 解除、入力電流の上限 1200mA。つまり契約は 15V
  - `REG01=11`: 充電モード、OTG 解除
  - `SYS=64`: 電源良好、高速充電中
  - `FAULT=00`
  - `vbus=usb-host` は、BQ の D+/D- 判定による表示で、PD の受電には関係しない
- **バッテリー:** 32%、4040mV、**電流 +2083mA / +2078mA**（充電中）
- **BM92T:** `S1=4E80`
  - 受電中（SPDSNK）、VSAFE、**データの役割=2（DFP）**
  - データの役割の交換（DR_SWAP）で UFP から DFP になったと考えられる。DR_SWAP の行そのものは写っていない。

## Windows（ユーザー報告）

**[事実]** R363 で、DST-C30SV と充電器をつないだ構成のまま、**Windows でもハブ経由の USB が使えた。** ユーザーの計測では、充電器側の出力が約14.7W（ハブ自身の消費も含む）。

**[事実]** **ハブの有線 LAN（RTL8153）で、Windows がネットワークにつながった。** 標準のドライバーで認識し、「Network 2」として、ネットワーク探索の確認ダイアログが出た。

**[推測]** 15V の契約での上限は 15V × 1.2A = 18W。14.7W はこれより下なので、入力電流の上限には当たっていない。充電の速さは、バッテリーが受け入れる電流（BQ の充電電流の設定は 2048mA）と、本体の消費で決まっている。

## 未確認

- **キーボードのレシーバー:** UsbIo に出ていない。挿していなかったのか、UEFI で FS の機器を列挙できない問題（R361/R362 と同じ）なのかは不明。
- **Windows での動作:** ハブ（USBHUB3）、レシーバー、RTL8153 の LAN、充電が続くかは、まだ試していない。
- **画面に出たが写っていない行:** 契約の PDO の一覧と、DR_SWAP の行（写真の範囲外）。
