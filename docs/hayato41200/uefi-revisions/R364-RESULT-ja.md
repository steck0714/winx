# R364 実機結果（2026-10-24）

**[事実]**
- **step 2 の途中で固まった。** 最後に表示されたのは `R364 step 2: CCLK -> PLLP, PLLX 48001201 -> 40003502 (1017600 kHz)...` で、その後に `PASS` も `FAIL` も出なかった。
- **前の状態は想定どおりだった。**
  - `PLLX_BASE=48001201`（691200 kHz）、`MISC=00040000`
  - `CCLK_POLICY=20008888`、`SUPER_DIV=00000000`
  - `VOUT=B7`、`VOUT_DVC=B7`（950 mV）
- **step 1 は成功した。** 電圧は 950 → 1025 mV（C3）で、PASS。
- **温度とバッテリー:** SoC=40℃、ボード=39℃、バッテリー 74%（+1115 mA で充電中）。

**[原因]** T210 では、CPU を PLLP で動かすのに、PLLP から CPU への分岐（`CLK_ENB_Y` の bit31、`PLLP_OUT_CPU`）が有効になっている必要がある。coreboot はこれを LP0 からの復帰のときにしか有効にしない（`tegra_lp0_resume.c`）。そのため、CCLK を PLLP（0x20004444）に切り替えた時点で CPU のクロックが止まり、固まった。

**[対応]** R365 では、切り替えの間の一時的なクロック源を CLK_M（38.4 MHz の発振器、ソース 0、ゲート無し）に変更した。
